# CD-Rhombus

Triangle grid drawing program by Leonard Somero

# Running

1. Install LÖVE from https://love2d.org
2. Clone this repository into a subfolder named _CD-Rhombus_ in your LÖVE folder
3. Run _love cd-rhombus_ from command prompt.

# Basic usage

CD-Rhombus uses the mouse primarily, with a few keyboard commands. You can see your current brush in the mouse position. Left-click to place a brush in the grid, right-click to remove.  
  
Press [1]-[9] to select from one of the default brushes. Middle-click to scroll through most recent brushes.  
  
To create a brush of your own, hold [Shift] and left-click on pieces in the grid you want copied into the brush. When you let go of Shift, the brush is saved and immediately made into your active brush. As a bonus, you can press [A] while holding Shift to automatically select all pieces in the grid.  

Now that you have a custom brush, you can try rotating it in 60 degree increments with the [R] key. You will soon discover how brushes and their rotations are a powerful tool for creating geometric art.  

# Useful commands

[P] = cycle palette  
[G] = toggle grid visible/hidden  
[C] = clear grid of pieces  
[F11] = toggle fullscreen  
[H] = animate history of grid  
[Delete] = delete active brush  

# View screenshots

Press [Tab] to display a random screenshot from the 'document' folder. Feel free to add your screenshots there. [Shift+Tab] returns back to the drawing board.
